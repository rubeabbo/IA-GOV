# Cápsula de proyecto y transferencia

Usar estos campos solo cuando aporten a la tarea; omitir los vacíos en lugar de rellenarlos. Mantener la cápsula normalmente por debajo de una página y vincular la fuente completa.

| Campo | Contenido |
| --- | --- |
| Proyecto y encargo | Nombre verificado, pregunta actual y producto esperado. |
| Corte | Fecha, versión, ámbito y universo a los que se refiere el estado. |
| Objetivo y alcance | Qué se busca lograr y qué queda fuera de esta ejecución. |
| Decisiones vigentes | Definiciones confirmadas, actor que las adoptó y fuente. |
| Evidencia decisiva | Indicador o hecho, valor, unidad, denominador, fuente y corte. |
| Cambio desde el corte previo | Alta, baja o modificación con su evidencia; no repetir lo estable. |
| Pendientes y dependencias | Qué falta, quién debe resolverlo si está explícito y próximo hito. |
| Conflictos | Fuentes incompatibles o no comparables, con motivo y estado. |
| Referencias | Enlaces o identificadores verificables a documentos y pasajes. |

Para un subagente, transferir únicamente: **pregunta delimitada → fuentes autorizadas → corte → salida esperada → criterios de aceptación → incertidumbres que debe reportar**. El subagente devuelve hallazgos con procedencia, no un nuevo relato general del proyecto.
