# Representation Router

Secuencia → flowchart/swimlane. Comparación → tabla/matriz. Arquitectura → diagrama. Métricas → dashboard. Concepto abstracto → metáfora/composición. Fotografía → raster. Símbolo geométrico → vector/SVG. Animación → storyboard + shots.
