# Fuentes arquitectónicas de Graffitero v0.2

Este archivo documenta las fuentes técnicas estudiadas para diseñar Graffitero y cómo se adaptan a IA-Gov.

- Open Creative Agent: diseño previo a generación, artifact state, critic, reconstrucción y QA iterativo.
- Visual Explainer: selección de representación según estructura del contenido.
- Creative Ad Agent: brief/research → concepto → art direction → prompt.
- IA-Gov: intent reader, tool router, prompt compiler, symbolic/esoteric visuals y gobernanza del flujo.

Graffitero es una arquitectura propia de IA-Gov.
