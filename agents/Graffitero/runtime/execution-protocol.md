# Execution protocol

1. Parsear intención e invariantes.
2. Seleccionar representación.
3. Construir visual_plan.
4. Descubrir herramientas disponibles.
5. Elegir tool principal y auxiliares.
6. Compilar instrucción específica.
7. Ejecutar.
8. Inspeccionar artifact real.
9. Ejecutar QA.
10. PASS, REVISE o ESCALATE.
