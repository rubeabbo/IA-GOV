# Índice de afirmaciones y matriz de conciliación

## Registro mínimo por afirmación

| Campo | Registrar |
| --- | --- |
| ID y texto | Afirmación atómica o valor exacto, sin paráfrasis que altere sentido. |
| Objeto | Indicador, decisión, acción, entregable o conclusión. |
| Clave | Universo, ámbito, período, unidad, granularidad y método. |
| Estado | Observado, calculado, estimado, propuesto, acordado o aprobado. |
| Procedencia | Fuente original, pasaje, fecha/corte, versión y responsable si consta. |
| Destino | Pieza final y lugar donde se usó o debería usarse. |

## Matriz de salida

| Asunto | Fuente A | Fuente B / salida | Diagnóstico | Regla aplicada | Acción / estado |
| --- | --- | --- | --- | --- | --- |
| … | Valor y corte | Valor y corte | Coincide / actualización / no comparable / contradicción / derivación errónea / pérdida semántica / insuficiente | Qué definición o fuente decide | Corrección concreta o validación pendiente |

**Ejemplos de criterio:** varias filas de un mismo `ID_AGENDA` pueden representar franjas de una agenda y no varias agendas; una oferta semanal formal y una oferta diaria neta no forman una contradicción; una propuesta que solo promete “optimización” puede haber perdido el método y entregable presentes en la fuente. Investigar cada caso antes de elegir un valor o reescribir una frase.
